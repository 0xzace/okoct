# V0.2 组件清单

## 已实现的基础组件

`BrandLogo`、`Container`、`SectionHeading`、`Badge`、`Button`、`Divider`、`Card`、`EmptyState`。

## 导航组件

`SiteHeader`、`SiteFooter`、`LanguageSwitcher`、`ThemeControl`、`Breadcrumbs`、`SearchTrigger`、`SearchDialog`。

## 内容和安全组件

`HeroPanel`、`TopicCard`、`FeaturedContent`、`ContentGrid`、`EditorialStandards`、`MedicalDisclaimer`、`SafetyNotice`、`EvidenceNote`、`AuthorCard`、`ReviewerCard`。

## 阅读模板组件

`ArticleHeader`、`ArticleMeta`、`ArticleBody`、`ReferenceList`、`RelatedArticles`，以及 `PageLayout`、`ArticleLayout`、`TopicLayout`、`LegalLayout`、`ErrorLayout`。

组件默认使用语义 HTML，只有搜索和主题偏好需要客户端脚本；所有交互状态必须有可读的文本或 ARIA 关系。
