# Roadmap

## V0.1 — 工程基础（当前）

状态：VERIFIED（本地证据已记录）。

- Astro 静态生成和基础页面。
- 三语言路由、字典、canonical、hreflang、sitemap、robots。
- Content Collections + Zod + 内容发布门禁。
- 单元、集成、E2E、构建和 SEO 产物验证。
- Docker/Nginx/CI 准备。

## V0.2 — 设计系统和搜索体验（DONE；专业内容门仍 Pending）

- 完成 Evidence Horizon 品牌、CSS Design Tokens、组件清单、布局规范和可访问性/动效规范。
- 完成三语言科学编辑型首页、主题/语言切换、真实空状态和 noindex 搜索入口。
- 保留 Pagefind 静态索引并增加渐进式搜索增强，不收集敏感健康信息。
- 完成响应式、主题、reduced-motion、键盘和截图验收；证据见 [V0.2 验证记录](../evidence/V0.2-VERIFICATION.md)。
- 真实作者、医学审核人、法律/合规负责人、证据存档流程和正式内容发布仍为 Pending。

## V0.2.1 — Visual Refinement & Production Quality（VERIFIED；专业内容门仍 Pending）

- 完成内容驱动首页、重复空状态收敛、体重管理方向 Hero 和 Evidence Horizon 视觉收敛。
- 完成移动端紧凑导航、Escape/焦点管理、主题同步和真实路由限制。
- 完成 axe、生产预览视觉测试和 Lighthouse 实验室基线；最终 Docker 证据见 [V0.2.1 验证记录](../evidence/V0.2.1-VERIFICATION.md)。
- 正式医学审核、法律/隐私门、真实用户性能和生产发布仍为 Pending。

## V0.3 — 实验和可观测性（Proposed）

- 记录 SEO 实验假设、基线、观察窗口、结果和限制。
- 评估隐私合规后的最小分析方案。
- 分离实验室性能和真实用户性能证据。

## 不在路线图默认范围内

数据库、CMS、用户账号、诊断、个性化治疗、购药、处方、药品推广和医疗咨询不属于默认路线；若业务要改变，必须重新获得明确批准并完成架构和法律评审。
