# Roadmap

## V0.1 — 工程基础（当前）

状态：VERIFIED（本地证据已记录）。

- Astro 静态生成和基础页面。
- 三语言路由、字典、canonical、hreflang、sitemap、robots。
- Content Collections + Zod + 内容发布门禁。
- 单元、集成、E2E、构建和 SEO 产物验证。
- Docker/Nginx/CI 准备。

## V0.2 — 内容治理和搜索体验（Proposed）

- 确定真实作者、医学审核人、法律/合规负责人和证据存档流程。
- 在审核流程通过后，添加少量真实、可追溯的健康教育内容。
- 设计专题聚类、搜索意图、内部链接和 Search Console 基线。
- 评估 Pagefind 搜索 UI，保持静态优先和无敏感数据收集。

## V0.3 — 实验和可观测性（Proposed）

- 记录 SEO 实验假设、基线、观察窗口、结果和限制。
- 评估隐私合规后的最小分析方案。
- 分离实验室性能和真实用户性能证据。

## 不在路线图默认范围内

数据库、CMS、用户账号、诊断、个性化治疗、购药、处方、药品推广和医疗咨询不属于默认路线；若业务要改变，必须重新获得明确批准并完成架构和法律评审。
