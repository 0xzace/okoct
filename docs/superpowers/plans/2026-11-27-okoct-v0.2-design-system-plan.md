# OKOCT Health V0.2 Design System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 OKOCT Health 的 V0.1 静态页面壳升级为可验证的三语言、双主题、科学编辑型设计系统和首页体验。

**Architecture:** 继续使用 Astro 静态生成与原生 `.astro` 组件；以 CSS Custom Properties/Tailwind 主题建立 token，布局组件复用 `BaseLayout` 的唯一 SEO 入口。搜索页为 noindex 的轻量 Pagefind 客户端增强，首页和内容/安全模块在无脚本时仍输出完整语义 HTML。

**Tech Stack:** Astro 7.4.13, TypeScript 6 strict, Tailwind CSS 4.3.5, Vitest, Playwright, Pagefind, pnpm.

**Spec:** `docs/superpowers/specs/2026-11-27-okoct-v0.2-design.md`

## Global Constraints

- 继续支持 `th`、`en`、`zh-Hans`，URL 前缀为 `/th/`、`/en/`、`/zh/`。
- 只生成真实存在且允许索引的本地化路由；搜索页为 `noindex,nofollow`，不进入 sitemap。
- 不发布未经审核的医学内容，不伪造人员、机构、研究、疗效或药品服务。
- 继续使用 Astro 原生组件和静态生成，不引入大型 UI 框架、数据库、CMS 或不必要依赖。
- 所有代码注释使用中文；不修改与 V0.2 无关的用户代码。
- 所有测试、构建、截图和阻塞状态都记录在 `docs/evidence/V0.2-VERIFICATION.md`。

## Review Focus

- 缺失本地化路径：语言切换和 hreflang 不能生成 `/zh/safety/` 等不存在链接；由路由/SEO 单元测试覆盖。
- 未审核内容：首页卡片和 Pagefind 输出不能泄漏 `draft`/`test-only` fixture；由集成和构建验证覆盖。
- 系统主题初始化：首次加载不能把深色系统用户闪成浅色；由 E2E 主题测试和实际截图覆盖。
- Thai/中文长文本：导航、按钮、卡片和文章阅读宽度不能裁切或横向溢出；由多语言响应式 E2E 覆盖。
- 键盘与 reduced-motion：焦点必须可见，非必要动画必须可禁用；由组件约定、CSS token 测试和 E2E 覆盖。
