# 编辑工作流

1. 以关键词、用户问题和主题覆盖创建 `ContentBrief`。
2. 编辑根据证据要求创建 Markdown/MDX 草稿。
3. 事实核查记录每个关键断言的来源。
4. 合格医学审核人员审核医学范围、风险和限制。
5. 合规负责人审核产品边界、措辞、隐私和泰国监管表述。
6. 翻译审核人员逐语言审核本地化标题、正文、元数据和术语。
7. 编辑批准具体 revision；构建门禁再次验证全部记录。
8. 只有门禁通过的 `published` 版本进入静态生成。

AI 可以协助草稿、结构或检查，但不能充当真实作者、医学审核人、法律审核人或发布批准人。未确定真实审核人员时，记录必须保持 Pending。

所有状态变化、审核决定、修订和纠错都必须在 Git 中可追溯。内部证据只用于审核和审计，不复制到 `dist/`。
