# 参考文献标准

## 允许的来源类型

监管文件、官方药品说明书、临床指南、系统综述、荟萃分析、临床试验、学术出版物、政府公共卫生资料和官方安全警示。

## 最低记录

每条 Reference 记录 `id`、类型、标题、发布者、作者、URL 或 DOI、发布日期、访问日期、法域、语言、验证状态、验证人和许可状态。未知信息保持 `null`，不能猜测 DOI、出版日期或监管批准。

## 验证边界

URL/DOI 校验和链接检查只能证明技术格式或可访问性，不能证明内容正确或适合医学结论。医学验证必须由真实合格人员完成并记录在 ReviewRecord 中。文章引用的参考资料发生关键变化时，文章需要重新评估。
