# OKOCT Health PRD V1.0

状态：Proposed；V0.1 只交付基础工程，不代表 V1.0 产品范围已全部实现。

## 1. 背景

OKOCT Health 面向泰国市场提供独立健康知识。初始主题方向包括体重管理、GLP-1、减重针相关医学安全知识和泰国监管政策，但任何具体文章都必须经过来源核验、专业医学审核和合规审核。

## 2. 用户与需求

- 普通读者：希望以自己的语言阅读可靠的一般健康知识。
- 内容审核人员：需要看到来源、状态、审核记录和翻译关系。
- 搜索用户：需要可索引、语义清晰、可访问的独立语言页面。
- 运营人员：需要可重复的构建、SEO 和发布验收证据。

## 3. 产品目标

- 提供三语言、独立 URL 的健康知识页面。
- 让每个可索引页面具备准确标题、描述、canonical、语言标记和内部链接。
- 让未审核内容无法进入公共页面、sitemap、结构化数据或生产构建。
- 在不收集敏感健康信息的情况下，建立可持续的内容和 SEO 工程体系。

## 4. 非目标

不做医院、诊所、药房、购药、代购、处方、在线诊疗、诊断、个性化剂量、疗效承诺、医疗联盟营销、用户健康档案、数据库 CMS 或账号系统。

## 6. 合规验收

任何正式内容发布都必须满足来源、事实核查、医学审核、合规审核、翻译审核和发布授权要求。自动化只验证结构和门禁，不授予医学或法律批准。

## 7. 指标

V0.1 只记录工程结果。LCP ≤ 2.5 秒、INP ≤ 200 毫秒、CLS ≤ 0.1 是目标值，必须在有代表性的实验室和真实用户数据中分别测量后再报告。
