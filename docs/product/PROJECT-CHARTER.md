# OKOCT Health 项目章程

## 项目身份

| 项目      | 内容                     |
| --------- | ------------------------ |
| 名称      | OKOCT Health             |
| 域名      | okoct.com                |
| 产品类型  | 独立、非商业健康知识网站 |
| 目标市场  | Thailand                 |
| 默认语言  | th                       |
| 支持语言  | th、en、zh-Hans          |
| V0.1 版本 | 0.1.0                    |

## 使命

通过有来源、边界清晰、可理解的健康教育内容，帮助读者形成更好的健康信息判断能力。网站不提供诊断、个性化治疗、处方、购药或医疗咨询。

## 价值原则

- 医疗安全和法律合规优先。
- 隐私和数据最小化优先。
- 内容必须可追溯并经过适当的人类审核。
- SEO 服务于准确性、可访问性和用户信任。
- 静态优先、移动优先、语义 HTML 和最小 JavaScript。

## 成功定义

V0.1 的成功是一个可构建、可测试、可审计的工程基础，不是搜索排名、流量、医疗效果或商业收入。正式内容发布前仍需要真实专业人员和合规负责人完成审核。
